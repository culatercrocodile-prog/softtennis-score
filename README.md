# ソフトテニス スコア記録

ソフトテニス（ダブルス）の試合をスマホから記録するPWAです。ビルド不要のプレーンHTML/CSS/JavaScriptで動作し、記録したデータはブラウザのlocalStorageにのみ保存されます（サーバーには送信されません）。

## 主な機能

- 1ポイントごとに「サーブの種類（1st/2nd）」「得点/失点」「決まり方（前衛・後衛どちらが行ったか含む）」をボタンで記録
- ゲームカウント・デュース・ファイナルゲーム（ゲームカウント3-3で7ポイント制に切替）を自動判定
- 自チーム・相手チーム双方のサービスゲーム/レシーブゲーム別ポイント取得率、決まり方の内訳を集計
- スコアシートを印刷用PDF・画面表示・CSV/JSONの3形式で出力
- オフラインでも使えるPWA（Service Workerでアセットをキャッシュ）

## 使い方

`index.html` をWebサーバー経由で開いてください（ESモジュールを使用しているため `file://` では動作しません）。

```bash
python -m http.server 8000
```

## テスト

ルールエンジンの単体テスト（Node.js）:

```bash
node --test
```
